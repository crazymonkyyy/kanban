# AI Thoughts

This folder contains all planning documents, reflections, and workflow documentation for AI development work.

## Purpose
- Centralize all AI planning and reflection documents
- Provide historical context for development decisions
- Document workflow processes and standards
- Support continuous improvement through lessons learned

## Folder Structure
- `WORKFLOW.md` - Standardized AI development workflow
- `ACTION_PLAN_FEEDBACK_LOOP.md` - Action plan for setting up feedback loops
- Planning documents for specific features or tasks
- Reflection documents analyzing completed work
- Process documentation and guidelines

## Usage
All AI development work should:
1. Begin with a planning document in this folder
2. Follow the standardized workflow process
3. Archive completed planning documents here
4. Reference existing documents for consistency and context
